Portfolio Overview:

Crescent View Hotel is a simulated hotel business used consistently throughout this MIT 8103 Advanced Database Systems continuous assessment portfolio. The Hotel Reservation System manages guest information, room records, bookings, and payment records. The portfolio covers database design, query optimisation, transactions and concurrency, NoSQL modelling with MongoDB, and a proposed distributed and cloud database design.

Portfolio Activities and Technical Evidence

Portfolio 1: Database Design and Modelling

The database was designed using relational modelling principles, including entities, primary keys, foreign keys, constraints, and normalization. An ER diagram was created using diagrams.net, and the database schema was implemented in MySQL. The design was supported by the ER diagram and SQL schema file.

Portfolio 2: SQL Queries and Query Optimisation

SQL queries were developed to retrieve booking details, calculate booking costs, summarize payments, list guest bookings, and identify available rooms. Query execution plans were examined using EXPLAIN, and an index was tested to investigate its effect on query performance.

Portfolio 3: Transactions and Concurrency

Transaction examples were implemented in MySQL to demonstrate COMMIT and ROLLBACK. The results were checked to confirm that committed changes were saved and rolled-back changes were cancelled. Transaction isolation was also examined.

Portfolio 4: NoSQL Data Modelling

MongoDB was used to create guest and booking collections for the Hotel Reservation System. Sample guest and booking documents were inserted and viewed using MongoDB Compass. Screenshots provide evidence of the records.

Portfolio 5: Distributed Databases and Cloud Deployment

This activity discusses a proposed distributed database and cloud deployment design for the Hotel Reservation System. Replication, sharding, and cloud deployment are discussed as design concepts; they were not implemented or tested as part of this practical work.
